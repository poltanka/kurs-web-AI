# Codex: одна назва — два різні помічники

Уяви: ти чуєш про Codex від OpenAI, шукаєш інформацію й знаходиш дві зовсім різні історії. В одній Codex — модель, яку вимкнули ще у 2023 році. В іншій — новий помічник програмістів, що з'явився у 2025-му. Обидві історії правдиві: під назвою Codex OpenAI випустила два різні продукти. Їхнє порівняння добре показує, як змінився штучний інтелект усього за кілька років.

## Codex №1: підказувач коду (2021–2023)

Спершу коротко: програма — це набір інструкцій для комп'ютера, записаний мовою програмування, наприклад Python. Писати такі інструкції — і є програмування.

Перший Codex — це мовна модель, нащадок GPT-3. Її донавчили на публічному коді з GitHub — найбільшого сайту, де програмісти зберігають свої проєкти. Codex умів перетворювати опис англійською мовою на код.

Найвідоміше застосування Codex — **GitHub Copilot**. Технічне прев'ю Copilot запустили 29 червня 2021 року, а 21 червня 2022 року сервіс став доступним для всіх охочих за 10 доларів на місяць або 100 доларів на рік.

Copilot працював як автодоповнення на клавіатурі смартфона, тільки для коду. Програміст починає писати функцію або коментар на кшталт «порахувати середню оцінку», а Copilot пропонує, як продовжити. Прийняти підказку чи ні, вирішує людина.

## Як перевіряли Codex: тест HumanEval

7 липня 2021 року дослідники OpenAI опублікували статтю про Codex. Щоб перевірити, наскільки добре модель програмує, вони створили тест **HumanEval** — 164 задачі мовою Python.

Кожна задача складається з опису функції та набору автоматичних перевірок. Наприклад, задача на зразок «Напиши функцію, яка отримує список чисел і повертає лише парні». Перевірки підставляють у функцію різні списки й дивляться, чи відповідь правильна. Модель пише код, а перевірки показують, чи він справді працює. Важливо не те, чи код схожий на правильний, а те, чи програма виконує потрібне.

Результати:
- Codex розв'язав 28,8% задач;
- GPT-3, яку не вчили спеціально на коді, — 0%.

28,8% — це менше третини. Але для 2021 року це був великий крок: модель, яка вчилася на прикладах коду, почала розв'язувати нові задачі. До того ж найбільша модель Codex у статті мала до 12 млрд параметрів — майже в 15 разів менше, ніж GPT-3.

Першим автором статті був Марк Чен, а серед співавторів — Ґреґ Брокман і Войцех Заремба, співзасновники OpenAI.

Важлива деталь: у статті зазначено, що в Copilot працювала окрема «виробнича» версія Codex. Тому популярне твердження «Copilot — це і є Codex» є спрощенням.

## Чому першу модель вимкнули

20 березня 2023 року OpenAI повідомила клієнтів, що припиняє роботу Codex у своєму API, тобто в сервісі, через який програми розробників звертаються до моделей. Уже 23 березня моделі вимкнули, а користувачам порадили переходити на новіші моделі OpenAI. Тож уся історія першого Codex в API вмістилася менш ніж у два роки: від відкриття в серпні 2021-го до вимкнення в березні 2023-го.

## Codex №2: агент-програміст (з 2025)

Через два роки назва повернулася, але вже для зовсім іншого продукту. Перший Codex був моделлю, тобто «двигуном» для інших програм. Новий Codex — готовий інструмент, з яким людина працює напряму:
- 16 квітня 2025 року OpenAI випустила **Codex CLI** — агента з відкритим кодом (його код може переглянути будь-хто), який працює в терміналі (текстовому вікні для команд на комп'ютері);
- 16 травня 2025 року з'явився хмарний **Codex** у ChatGPT на моделі codex-1 — версії «міркувальної» моделі o3, налаштованій для розробки програм. «Міркувальна» модель перед відповіддю розбирає задачу покроково;
- 6 жовтня 2025 року Codex став загальнодоступним.

Згодом Codex отримував нові моделі: GPT-5-Codex, GPT-5.2-Codex, GPT-5.3-Codex. Про GPT-5.3-Codex (лютий 2026) OpenAI заявила, що це її перша модель, яка допомогла створити саму себе.

## Що таке ШІ-агент

Головна різниця між двома Codex не в розмірі моделі, а в способі роботи:
- **помічник-підказувач** пропонує рядок коду, а все інше робить людина;
- **агент** отримує завдання й сам виконує кілька кроків: пише код, запускає тести, виправляє помилки й пропонує готові зміни.

Порівняти можна з навігатором і таксі. Навігатор підказує, куди повернути, але кермо в твоїх руках. Таксистові ти просто називаєш адресу.

Наприклад, агентові можна дати завдання: «Додай на сайт кнопку перемикання темної теми». Агент знайде потрібні файли, напише код, запустить тести, а якщо щось зламалося — спробує виправити. Програмістові лишається переглянути результат. Тести тут — це невеликі програми, які автоматично перевіряють, чи код працює правильно; їх запускають після кожної зміни, щоб нічого не зламати.

Хмарний Codex працює в ізольованому середовищі — окремій «пісочниці», де його дії не зачіпають нічого зайвого. Результат він подає як **pull request** — запит на внесення змін, який програміст може переглянути й прийняти або відхилити.

## Порівняння

Головні відмінності — в одній таблиці:

| | Codex №1 | Codex №2 |
|---|---|---|
| Що це | Модель, що підказує код | Агент, що сам виконує завдання |
| Роки | 2021–2023 | з 2025 |
| Де працював | GitHub Copilot, API OpenAI | ChatGPT, термінал, редактори коду |
| Хто робить основну роботу | Людина | Агент, а людина перевіряє |

## Що варто перевіряти людині

Навіть найсучасніший агент може помилятися. Тому:
- перевіряй, чи код справді робить те, що потрібно, а не лише «запускається»;
- не використовуй у важливих проєктах код, якого зовсім не розумієш;
- не передавай ШІ-інструментам паролі та особисті дані;
- пам'ятай: відповідальність за результат лишається на людині.

Агенти не скасовують потребу вчитися програмувати. Навпаки: щоб перевірити роботу агента, треба розуміти, що він зробив.
