## 2. Що змінилося в дизайн-системі під час роботи

- **Вік аудиторії — 14–18 років** (ТЗ оновлено з 14–19). У формах діапазон 14–18.
- **Маскот затверджено: єнот Байт** (`assets/Mascot/raccoon-avatar.svg`). **Логотип — текстовий**: «ШІ-майстерня» шрифтом Unbounded.
- **Кольори названо за призначенням** (`bg`, `surface`, `ink`, `ink-muted`, `primary`, `accent`, `line-strong`, `focus-ring`, `success`, `danger`…), у кожного — значення для світлої й темної теми. Контраст усіх пар перевірено за WCAG AA: проходять в обох темах.
- **Стан ніколи не передається лише кольором**: пройдено / закрито / помилка / активна вкладка мають іконку і слово.
- **Шкала шрифтів** для телефона й ноутбука (Unbounded — заголовки, Manrope — текст, JetBrains Mono — код), основний текст не менше 16px. Шрифти під ліцензією OFL 1.1 (перевірено на сторінках виробників), їх можна розміщувати на власному сервері.
- **Усі розміри — токени**: відступи `space-half`…`space-9`, рамки `stroke-*`, фокус `focus-width` / `focus-offset`, іконки `icon-*`, елементи `size-*`, шрифти `fs-*` / `lh-*`, шари `z-*`. У CSS немає значень, заданих вручну (винятки описано в README). Окремого токена тіні кнопки немає: вона складається з `btn-depth` і `cta-edge`.
- **Додано компоненти** (усі класи з префіксом `sm-`, превʼю зі станами в обох темах):
  - форми: `FormField` (поля, вік, контакт, згода, багаторядкове поле з лічильником), `Checklist`;
  - навчання: `LessonCard`, `DoneButton` («Урок пройдено»), `VideoBlock`, `Screenshot`, `StatusPill`;
  - каркас: `Logo`, `SkipLink`, `Header`, `Footer`, `Card`, `Avatar`, `HeroBadge`, `Switchers` (мова УКР / EN, тема);
  - мотивація: `ModuleBadge`, `Certificate`;
  - кабінет учителя: `ProgressTable`, `InviteCode`, `ReviewQueue`;
  - прогрес і контент: `ModuleProgress` (прогрес модуля), `Accordion` (FAQ «Для батьків»), `ArticleCard` (картка статті блогу), `Breadcrumbs` (хлібні крихти з `BreadcrumbList`).
- **Сторінка «Правила»** (`rules.md`): шкала відступів, сітка, точки переходу (до 767px, від 768px, від 1024px), радіуси, вигляд фокусу, «можна / не можна» для кожного компонента.
- **Рівень доступності — WCAG 2.2 AA**: у README описано нові критерії 2.2 (фокус не закритий, розмір цілі, перетягування, послідовна допомога, повторне введення, доступна автентифікація).
- **Виправлено**: розмір кнопки-посилання (усі елементи `sm-` — `box-sizing: border-box`), колір тексту в акцентній кнопці-посиланні й логотипі.

## 3. Технічні умови

- **Платформа:** WordPress на сервері музею.
- **Плагіни:** лише безкоштовні.
- **Відео:** YouTube, доступ за посиланням; вбудовування «клік для завантаження» через `youtube-nocookie.com`.
- **Теми:** світла й темна; початкова — за `prefers-color-scheme`, вибір зберігається; без «спалаху» при завантаженні.
- **Мови:** українська (основна, у корені `/`) і англійська (`/en/`, лише публічні сторінки й демо-уроки); `hreflang` uk / en / x-default, self-canonical.
- **Доступність:** WCAG 2.2 AA. Нові критерії 2.2 і як система їх виконує — у README дизайн-системи, розділ «Доступність і адаптивність».

## 4. Рішення, узгоджені 29.10.2026

1. **Сервер:** WordPress на сервері музею (ТЗ оновлено).
2. **Доступність:** WCAG 2.2 AA (у ТЗ і в дизайн-системі).
3. **LMS-плагін — обрати після перевірки.** LearnDash платний, тож не підходить (у ТЗ його вже прибрано). **Перше завдання для Claude Code:** на тестовій інсталяції порівняти безкоштовні LearnPress, Tutor LMS (безкоштовна версія) і Sensei LMS за критеріями: лінійне відкриття 24 занять; тести з автоперевіркою; завдання з текстовою відповіддю й перевіркою вчителем; реєстрація учня за кодом класу; прогрес учня й класу для вчителя; сумісність із Polylang (безкоштовний) і власною темою. Результат — таблиця з висновком; чого бракує в плагіні, дописати кодом теми.
4. **Відео:** YouTube з доступом за посиланням, вбудовування «клік для завантаження»: спершу постер із власного сервера, iframe `youtube-nocookie.com` з'являється лише після натискання. Субтитри й стенограма обов'язкові. Деталі — README компонента `VideoBlock`.
5. **Шрифти лишаються з Google Fonts** (`@import` у `bundle.css`). У політиці конфіденційності обома мовами назвати Google Fonts і YouTube серед сторонніх сервісів.
6. **Таблиця наставника:** лише ім'я та ініціал прізвища, без email (макети вже оновлено; email — лише в картці учня).

## 5. Відкриті питання

Поки на них немає відповіді, не вигадувати значення: у верстці лишати помітні заглушки (`[ДОМЕН]`, `[ДАТА СТАРТУ]`, `[EMAIL ДЛЯ ЗАЯВОК]`) і не блокувати ними решту роботи.

| Питання | Що відомо зараз | Від чого залежить у верстці | Хто вирішує |
| --- | --- | --- | --- |
| **Домен** | Робоча назва — shi-maisternia; у ТЗ відкрито: перевірити вільність у зонах .ua / .com.ua. Остаточного домену немає | canonical, hreflang, XML-sitemap, посилання-запрошення класу, адреси в листах, налаштування Search Console й Matomo | Замовник |
| **Дата старту** | У ТЗ: жорстких термінів немає, запуск поетапний (MVP → повна версія → англійська версія). Конкретної дати немає | Тексти на головній («Новий набір…»), бейдж героя, термін дії кодів класу, план етапів | Замовник |
| **Хто відповідає на заявки** | Текст форми на головній: «Заявка надійде організаторам курсу на пошту». Конкретної людини чи адреси, а також терміну відповіді немає | Адреса отримувача листів із форми, текст підтвердження після надсилання, політика конфіденційності (хто обробляє дані заявки) | Замовник |
| **Чи потрібен блок для батьків** | У ТЗ є окрема сторінка «Для батьків» (які дані збираються, вікові обмеження ChatGPT і Gemini) і FAQ для батьків як цільова сторінка SEO. Чи потрібен ще окремий блок на головній — не вирішено | Структура головної, меню й підвал (посилання на допомогу — WCAG 2.2, 3.2.6), компонент-акордеон для FAQ (`Accordion` у системі вже є) | Замовник |

## 6. Як передати в Claude Code

- Дизайн-систему й макети передаємо в Claude Code **самими артефактами**: систему — командою `/design-sync`, макети — командою `/design`, з посиланнями з розділу 1. Не PDF і не скриншоти: так Claude Code отримує токени, CSS, розмітку компонентів і структуру екранів, а не картинку.
- Разом із ними — цей звіт і ТЗ (файл .docx або розділи «ТЗ сайту» й «Передача в Claude Code» у дизайн-системі).
- Перед початком верстки звірити, що в Claude Code підтягнулася остання версія обох артефактів.

## 7. Як верстати

- Тема WordPress бере `components/bundle.css` із системи; токени — з `tokens.json` (згенерувати `tokens.css`: світла тема на `:root`, темна на `[data-theme="dark"]`).
- Розмітку компонентів брати з README компонентів, класи не перейменовувати. Каркас кабінетів у макетах уже на компонентах системи `Header`, `Footer`, `Card`.
- Перевіряти кожну сторінку на 360, 375, 768, 1024 і 1440px в обох темах.
