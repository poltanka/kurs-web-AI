# Handoff: сайт курсу «ШІ-майстерня»

Оновлено 10.11.2026 (друга частина сесії). Попередня версія — 04.11.2026.

## Мета

Зробити навчальний сайт для учнів 14–18 років про ChatGPT, Codex і Gemini за ТЗ у цій папці:
- платформа — WordPress на сервері музею, лише безкоштовні плагіни;
- публічна частина з формою заявки (UA + `/en/`);
- закрита частина: кабінети учня й учителя, 4 модулі, 24 уроки.

Першим запускаємо MVP, який перевіримо на одному класі. Тексти публічних сторінок мають бути зручні й для дорослих 40+ (батьки, вчителі): великий шрифт, високий контраст, великі кнопки.

## Прийняті рішення

### Нові (10.11.2026)

- **Сторінка програми курсу — `programa.html`** (майбутня `/programa/`). Окремої короткої сторінки немає; `program.html` видалено.
- **Форма заявки на головній отримує `id="apply"`.** Усі кнопки «Залишити заявку» ведуть на `/#apply` (так уже зроблено в `programa.html`).
- **Основний текст публічних сторінок — не менше 18px на всіх ширинах.** Робимо це перевизначенням у CSS сторінки (`programa.css`, далі — в CSS теми для публічних шаблонів), а не зміною токенів: кабінети лишаються за дизайн-системою (16px на телефоні). Користувач не висловив переваги, тож обрано рекомендований варіант.
- **`plan.md` затверджено** користувачем.
- **Джерело назв занять — `Програма_курсу_ШІ_для_підлітків.docx`.** У ТЗ назв немає; беремо дослівно, нічого не вигадуємо. «Мозок агента» в модулі 4 — це «Додаткове заняття» з програми.

### Чинні з 04.11.2026

- **Назви:** «ШІ-майстерня» — назва сайту, «Всі можливості AI для роботи: реальні задачі та їхні рішення» — назва курсу.
- **Фон заглушки** — завжди `#111318` (токен `bg` темної теми). Решта кольорів у `index.html` тимчасові, не звірені з `tokens.css`.
- **Шрифти** з Google Fonts: Unbounded — заголовки, Manrope — текст. Апостроф — типографський ’.
- **Технічний підхід** — власна класична PHP-тема `shi-maisternia`, класи `sm-` не перейменовуємо.
- **Скриншоти лишаються,** але урок зрозумілий без них: підпис із датою, одна медіатека, перевірка перед кожним модулем.
- **Перевірка завдань:** тести — система; більшість «напиши промпт» — самоперевірка за чек-листом; вчитель перевіряє ~1 ключове завдання на модуль і фінальний проєкт. Наступний урок відкривається після здачі, а не після оцінки. Без автоперевірки через AI API в MVP.
- **З ТЗ і `handoff-claude-code.md`:** WCAG 2.2 AA, Polylang, відео через `youtube-nocookie.com` з «клік для завантаження», у таблиці вчителя лише ім'я та ініціал прізвища.
- **Правила дизайн-системи (`handoff-claude-code.md`):** стан ніколи не передається лише кольором (іконка + слово); усі розміри й кольори — лише токени, без значень, заданих вручну; `tokens.css` генерується з `tokens.json` (світла тема на `:root`, темна — `[data-theme="dark"]`); точки переходу 768 і 1024px; кожну сторінку перевіряємо на 360 / 375 / 768 / 1024 / 1440px у світлій і темній темах.
- **Для аудиторії 40+ на публічних сторінках:** великий шрифт (див. рішення про 18px), високий контраст, великі кнопки, видима рамка фокуса.

## Відкриті питання

### Нові (10.11.2026)

- **Підписи 14px на `programa.html`.** Основний текст уже 18px, але підписи й позначки з дизайн-системи лишилися 14px: «Результат модуля», «Підказка Байта», «Краще на комп'ютері», назви інструментів, вік сервісів, номер версії паспорта, примітки `.ty-cap` і `.l-note`. Частина з них — повні речення (наприклад, «Заняття відкриваються по черзі…»). Вирішити, чи піднімати їх до 16px для аудиторії 40+.
- **Посилання `/#apply`, `/demo/1/`, `/login/` у `programa.html` абсолютні від кореня сайту.** На WordPress працюватимуть, а при відкритті файлу локально — ні. Для локального перегляду це не помилка, але треба пам'ятати.
- **Хто створив `programa.html` і `assets/`** і чи це остання версія дизайн-системи — звірити з артефактом за посиланням у `handoff-claude-code.md`.
- **`plan.md` відстає від стану папки.** У розділі «Контекст» написано, що дизайн-систему «ще не підтягнуто», а вона вже частково є в `assets/`. Нових рішень від 10.11.2026 (`programa.html`, `#apply`, 18px) у плані немає — вони записані лише тут. План затверджено, тому без дозволу користувача його не правимо.
- **Локальний сервер.** `preview_start "static"` з `launch.json` не стартує (Python не має дозволу на поточну папку); сторінка відкривається з уже запущеного сервера на `127.0.0.1:8765`. Звідки той сервер — не з'ясовано.

### Чинні з 04.11.2026

- **LMS-плагін:** LearnPress, Tutor LMS (безкоштовна версія) чи Sensei — після порівняння на тестовій інсталяції.
- **Вирішує замовник:**
  - домен (`[ДОМЕН]`);
  - дата старту (`[ДАТА СТАРТУ]`);
  - адреса для заявок (`[EMAIL ДЛЯ ЗАЯВОК]`);
  - чи потрібен окремий блок для батьків на головній;
  - торговельна марка;
  - відповідність закону про персональні дані (юрист школи);
  - чи має школа Google Workspace for Education;
  - чи доступний Codex на безкоштовному плані ChatGPT.
- **Сервіси з програми, яких немає в ТЗ:** Google Таблиці, GitHub, Discord, Ollama — згадати на сторінці «Для батьків» і в політиці конфіденційності.

Паралельно, коли робитимемо головну: форма заявки з `id="apply"` і основний текст 18px.
